Paper Order Guide walkthrough

“My paper order was canceled. Did any shares fill?”

Follow one sample order
The Offline order lab shows ten empty squares when a synthetic paper order is accepted. The pointer selects Partial fill and three squares turn green. On Canceled, the same three squares stay green. Three shares filled on this sample order and the other seven were canceled. The customer has supplied only a status, so their own fill count is still unknown.

Search the customer's question
The exact ticket is run through two native Thally searches. The first page result is “Check how much of an order filled.” The first MCP section result is “Did any shares fill before cancellation?” The returned excerpt says to check the customer's order record.

Search a writer's question
In the same form, a writer asks, “Our help article reads well in the browser. How can I check which excerpt an assistant will get for a ticket and tell if changing the wording helped?” Running that query against the same index returns “Test your answer with Thally section search.” Opening the result lands on that heading in the teaching article.

Edit the passage
The exercise shows a first-ranked excerpt from a recorded learner build. It assigns the sample order's three fills to the customer and marks the ticket resolved. The writer chooses Edit a copy and types, “A canceled order can have earlier fills. Look up the customer’s own paper order and read filled_qty.” The draft stays in the browser tab. To measure a wording change, copy the revised passage into the source, rebuild the learner site, and rerun the original ticket against that preview.

Reply to the customer
The customer’s section result opens the cancellation heading in the troubleshooting guide. Use the customer's Alpaca order ID to look up their existing paper order and read filled_qty. Zero means no shares filled. A positive value gives the total that filled before cancellation. With only the ticket in hand, the reply is, “Could you share the order ID so I can check how many shares filled?”
